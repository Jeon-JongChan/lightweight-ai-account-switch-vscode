# README 한국어·영어 병기

- 원인: README의 대부분이 한국어로만 작성되어 영어 사용자가 설치 방법과 지원 범위·제약을 읽기 어려웠다.
- 수정: 한국어 원문 바로 아래에 괄호로 영어 번역 73 개를 추가했다. 표와 Mermaid 라벨은 셀·노드 안에서 줄바꿈하여 번역했다. PowerShell 예제의 번역은 주석으로 넣었다.
- 범위: README.md와 이 보고서. 기존 작업 중인 소스 코드와 기존 문서 내용은 유지했다.
- 확인: 번역 대상 수와 적용 수 일치, 코드 블록 닫힘 확인. 한국어 원문 전체와 기존 명령·경로·링크 보존, 각 한국어 줄의 번역 배치를 추가 확인했다.
- 미확인: 실제 Markdown·Mermaid 렌더링과 VSIX 재패키징은 실행하지 않았다.
