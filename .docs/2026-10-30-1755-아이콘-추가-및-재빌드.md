# 아이콘 추가 및 재빌드

- 원인: 확장 매니페스트에 아이콘이 없어 확장 목록에서 전용 아이콘이 표시되지 않았다.
- 수정: 검은 배경·차분한 하늘색과 흰색의 계정 전환 아이콘을 resources/icon.png에 추가하고 package.json의 icon과 .vscodeignore의 포함 규칙을 연결했다. 상태 표시줄의 기존 아이콘은 유지한다.
- 생성 방식: 기본 제공 image_gen 도구를 사용했다. 최종 편집 프롬프트: “Edit the latest grayscale account-switcher extension icon. Recolor ONLY the gray left account silhouette and gray top curved arrow to calm soft sky blue #87CEEB. Keep the right account and lower arrow white, and background pure black. No neon, no cyan fluorescence, no glow. Preserve all shapes, spacing and composition exactly. Square PNG.”
- 재빌드: build.ps1 package로 TypeScript 컴파일과 VSIX 생성을 수행하고 패키지 안의 매니페스트·아이콘 포함 여부를 확인한다.
- 결과: TypeScript 빌드와 VSIX 생성에 성공했다. 설치 파일은 dist/ai-account-switcher-lite-0.1.0.vsix이며 아이콘을 포함한 16개 파일, 약 626 KiB이다. 아이콘 원본은 약 729 KiB로 패키징 도구의 큰 이미지 안내가 발생했으나 패키징은 정상 완료됐다.
- 제한: 현재 .tools/.test/check.cjs가 없어 npm test는 실행하지 않는다. 실제 VS Code 설치 화면의 표시는 확인하지 않는다.
